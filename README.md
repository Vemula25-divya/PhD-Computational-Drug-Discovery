# Virtual Screening Workflows for Drug Discovery

This repository contains virtual screening workflows developed during my PhD research in computational drug discovery.

## Overview

The notebooks demonstrate various stages of virtual screening and hit identification workflows, including:

* Compound library preparation
* Ligand filtering
* Chemical data processing
* Virtual screening strategies
* Hit prioritization workflows
* Cheminformatics analyses

## Repository Structure

### Virtual_Screening

* RelA.ipynb
* Otava.ipynb
* IBM MEGx Asinex Screening.ipynb
* Screening Terp_Alk_Small.ipynb
